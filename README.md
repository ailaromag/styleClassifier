# StyleClassifier

Una aplicació web que classifica el teu estil de vestir en temps real amb visió per computador.

Demo: [styleclassifier.netlify.app](https://styleclassifier.netlify.app/)

---

## Fase 1 — Adaptació per a nins

**Data límit:** abans de Pascua (30 de març - 1 d'abril)

Objectiu: adaptar el site per a nins.

- [x] Posar overlays d'objectes característics per cada estil (corona, ulleres de sol, etc.). L'overlay s'ajusta al cap i el segueix en directe (actualització asíncrona dels frames).
- [x] Toggle Mode Adults / Mode Kids
- [x] Canviar els noms de les classificacions per a que siguin kid-friendly
- [x] Galeria amb les fotos dels nins anteriors

Idees extra (no realitzades):
- [ ] "Superpoders": detectar les mans i que emanin efectes temàtics (flors per CottageCore, pilotes de basket per Streetwear, llamps per Rockstar,etc)

## Fase 2 — Millores d'interfície i posada a punt per la fira de la ciència

**Data límit:** Fira de la Ciència, 7-9 de maig

Objectiu: millorar la interfície i deixar-ho a punt per la fira.

- [x] Millorar la interfície per a que es vegi bé en pantalla completa a portàtils
- [x] Millorar l'aspecte del gallery wall per a que pareguin fotos polaroid amb la classificació
- [x] Pop-up: que s'obri un nou browser quan es fa una classificació per a que el nin pugui fer una foto
- [x] Interfície responsive per a mòbils (amagar imatges laterals)

Idees extra:

- [ ] Reentrenar el model amb més imatges
